# Repository instructions

- Whenever a change affects user experience, update the `This fork` section in `README.md` in the same change.
- Keep that section a concise summary of current differences from upstream: short bullets describing user-visible behavior, without implementation details. Update or combine existing bullets for related changes instead of growing a chronological changelog.
- Confine fork-specific README edits to that introductory section. Preserve the original upstream README below the separator and the assets it references unless the user explicitly requests otherwise.
